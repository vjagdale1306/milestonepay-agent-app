# MilestonePay Agent

MilestonePay Agent is an automated milestone-based escrow and payment verification platform built for hackathons, freelancers, and clients.

## Key Features
- **Escrow via Authorization**: Holds client funds securely using PayPal Authorizations on a per-milestone basis.
- **AI-Powered Work Verification**: Analyzes deliverables and criteria to verify milestone completion.
- **Automated Capture & Payout**: Seamlessly captures authorized funds and triggers payouts upon successful verification.

## Tech Stack
- **Backend**: Node.js, Express, SQLite
- **Frontend**: React, Vite
- **Integrations**: PayPal REST APIs (Sandbox mode, USD), LLM Verifier Service
